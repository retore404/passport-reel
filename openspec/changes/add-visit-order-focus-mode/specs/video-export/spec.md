# Spec Delta

## MODIFIED Requirements

### Requirement: プレビューと同じ内容の動画
システムは、プレビューで選んでいる表示モードについて、プレビューと同じコマの内容とタイミングのアニメーションを、縦横比 9:16（1080×1920）の動画ファイルとして書き出さなければならない（SHALL）。動画の長さはプレビューの再生時間と一致しなければならない（SHALL）。動画に音声を含めてはならない（MUST NOT）。

#### Scenario: 動画の長さと解像度
- **WHEN** 年ごとの表示で、記録のある年が 3 つあり、まとめの国名が 1 ページに収まるタイムラインを書き出す
- **THEN** 1080×1920 で長さ 10 秒の、音声のない動画ファイルができる

#### Scenario: 内容がプレビューと一致する
- **WHEN** 年ごとの表示で書き出した動画の 4.5 秒の位置を表示する
- **THEN** プレビューで再生位置を 4.5 秒にしたときと同じコマ（3 つ目の年）が表示される

#### Scenario: 1 か国ずつの表示を書き出す
- **WHEN** 表示モードを「1 か国ずつ」にして、訪問が 5 件あり、まとめの国名が 1 ページに収まるタイムラインを書き出す
- **THEN** 長さ 12 秒の動画ができ、3.3 秒の位置にはプレビューと同じ 3 つ目の訪問のコマが表示される
