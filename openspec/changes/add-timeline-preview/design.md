# Design

## Context

- 訪問記録は `useVisitRecords` が `{ year, country }[]` として持っている（`openspec/specs/visit-records`）。
- 地図は `drawWorldMap(ctx, size, countries, visited)` で描く。この関数は同期的で DOM に依存しないので、任意の Canvas とサイズで描ける。国境データは 50m 解像度で、1 回の描画では全部の国のパスを描く。
- 動画の書き出し（#5）では、WebCodecs で 1 フレームずつ「時刻 t のコマ」を描いてエンコードする（`docs/spikes/video-export.md`）。
- コマの構成（上部・中央・下部の内容と配色）は `docs/design-guidelines.md` の「将来の画面の指針 > プレビュー（#3）」で承認済みである。
- ユーザーとの合意事項は次のとおり。
  - コマは文字も含めてすべて Canvas に描く。
  - 1 年のコマは 2 秒、まとめのコマは 4 秒とする。

## Goals / Non-Goals

**Goals:**

- 「時刻 → コマの状態 → 描画」を純粋な関数の連なりにし、プレビューと #5 の書き出しで同じものを使えるようにする。
- タイムラインの算出、時刻とコマの対応、文字の折り返しを単体テストで確かめられるようにする。

**Non-Goals:**

- 動画の書き出しと書き出しボタン（#5）。
- 地球儀表現（#7）、BGM（#10）。
- コマの間のトランジション（スライドや拡大縮小）。コマの切り替えは即時とし、コマの中のアニメーションだけを持つ。
- 再生速度の変更、コマの長さの設定。

## Decisions

### モジュール構成

`src/timeline/` に次を置く。

- `timeline.ts`：`buildTimeline(records)`。年ごとの `{ year, newCountries, revisitedCountries, cumulativeCount }` と、まとめ `{ firstYear, lastYear, countries }` を返す。国の並びは日本語名の順とする。
- `timing.ts`：時間の定数（`YEAR_SECONDS = 2`、`SUMMARY_SECONDS = 4`）と `totalDuration(timeline)`、`frameAt(timeline, t)` を置く。`frameAt` は `{ kind: "year", index, elapsed }` または `{ kind: "summary", elapsed }` を返す。t は 0 から全体の長さの範囲に丸め、t がちょうど全体の長さのときはまとめのコマの最後の状態にする。
- `drawFrame.ts`：`drawFrame(ctx, width, timeline, frame, mapLayer)`。コマを基準の大きさ（1080×1920）の座標系で描き、`ctx.scale(width / 1080)` で任意の大きさに合わせる。
- `textLayout.ts`：国名を「、」でつなぎ、指定の幅で折り返し、最大行数を超えた分を「ほか N か国」にまとめる関数を置く。幅の計測は引数で受け取り、テストでは計測のフェイクを渡す。
- `usePlayback.ts`：`requestAnimationFrame` で再生時刻を進めるフック。再生・停止・最初から・位置の移動を持ち、最後まで進んだら止まる。
- `PreviewScreen.tsx`：プレビュー画面。Canvas、操作部品、PC のコマ一覧を置く。

### コマの配置（基準 1080×1920）

| 位置 | 内容 |
| --- | --- |
| 上部（y ≈ 120〜620） | 小さく字間を広げたアプリ名、大きな年（太字）、「初めて訪れた国 +N」と国名（地図と重ならないよう最大 2 行。再訪だけの年は「再訪：」に続けて国名） |
| 中央（y ≈ 660〜1340） | 地図。幅いっぱい（1080）で、高さは地図の縦横比から決める |
| 下部（y ≈ 1480〜1800） | 累計の国数（大きな数字、`--accent`）と「か国」、全コマ中の位置を示す進捗バー |

まとめのコマでは、上部に期間（例：2016–2024）を置く。中央には全訪問国をハイライトした地図、その下に訪れた国の一覧（小さめの文字で折り返し、上限を超えた分は「ほか N か国」）を置き、下部に累計の国数を置く。

文字は CSS と同じ端末のサンセリフ体（`--font-sans` と同じ指定）で描く。大きさはすべて基準の幅 1080 に対する px で決めるので、拡大・縮小しても比率は変わらない。

### コマの中のアニメーション（年のコマの経過時間 `elapsed` で決める）

- 0〜0.6 秒：その年に初めて訪れた国が、ハイライト色から強調色（`--accent-strong`）へ変わり、光彩が強まる。その後は強調色のまま保つ。
- 0〜0.6 秒：累計の国数が、前の年の値から今年の値へ増える（ease-out）。
- 0〜0.3 秒：上部の文字がフェードインする。
- まとめのコマ：0〜0.5 秒で一覧がフェードインする。

いずれも `elapsed` の関数なので、同じ時刻なら必ず同じ絵になる（spec の「時刻だけから一意に決まる」）。

### 地図の描画と負荷

- 50m 解像度の地図を毎フレーム全部描くと、スマートフォンでは 60fps を保てないおそれがある。そこで地図は 2 層に分ける。
  - **下地：** 「その年より前までの累計」をハイライトした地図。年（とまとめ）ごとにオフスクリーン Canvas に描いてキャッシュする（`mapLayer`）。
  - **強調：** その年に初めて訪れた国だけを、毎フレーム下地の上に描き重ねる。
- 強調の描画は `drawWorldMap.ts` に `drawEmphasizedCountries(ctx, size, countries, codes, strength)` として追加する。`strength`（0〜1）で色の混ぜ具合と光彩（`shadowBlur`）を決める。小さな国にはマーカーも強調色で描く。既存の `drawWorldMap` は変えない。
- キャッシュは描画結果を変えない最適化なので、動画の書き出しでも同じキャッシュを使える。

### 画面の切り替え

- `App.tsx` に `view: "records" | "preview"` の状態を持つ。URL には反映しない。
- **PC：** 上部バーの右に「記録」「プレビュー」の切り替えボタンを置く。プレビュー画面は、中央に 9:16 のプレビュー（領域に収まる最大の大きさ）、右に幅 320px のパネルを置く。パネルにはコマの一覧（年とまとめ、表示中のコマを強調、押すとそのコマの先頭へ移動）を置く。
- **スマートフォン：** 画面下に高さ 64px のタブ（記録／プレビュー）を置く。記録の画面の「＋ 記録を追加」ボタンはタブの上に置く。プレビュー画面は、上にプレビュー、下に操作を置く。
- 操作の並びは「最初から再生」「再生／停止」「再生位置のバー」とする（ガイドラインのとおり）。再生位置のバーは `<input type="range">` を使う。

### プレビュー Canvas の解像度

表示する大きさ × devicePixelRatio を内部解像度にし、`drawFrame` に幅を渡す。1080×1920 で描いて縮小するより描画の負荷が小さく、高 DPI 画面でもぼやけない。

## Risks / Trade-offs

- [スマートフォンでの描画負荷] 強調の国が多い年（1 年に 20 か国など）は、毎フレームの描き重ねが重くなる → 光彩が変化するのは最初の 0.6 秒だけなので、それ以降は「下地 + 強調」をまとめてキャッシュした絵を使う。
- [端末によるフォントの違い] Canvas の文字は端末のフォントで描くので、端末ごとに字形と幅が少し変わる → 折り返しは描画時に実際の幅で計算し、はみ出さないようにする。動画は書き出した端末のフォントで固定される。
- [国名の多い年] 1 年に多くの国を訪れると国名が収まらない → 年のコマは最大 2 行、まとめのコマは最大 4 行で打ち切り、「ほか N か国」とする。
