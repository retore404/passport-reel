# Design

## Context

- コマは `drawFrame(ctx, width, timeline, frame, layers)` で、基準の大きさ 1080×1920 の座標系に Canvas で描いている。プレビュー（`PreviewScreen.tsx`）と動画の書き出し（`exportVideo.ts`）が同じ関数を使う。
- 時刻とコマの対応は `timing.ts` の純粋な関数（`totalDuration`、`frameStartTimes`、`frameAt`）で決めている。呼び出し元は `PreviewScreen.tsx`（再生・シーク・コマの一覧）、`drawFrame.ts`（進捗バー）、`exportVideo.ts` と `useVideoExport.ts`（フレーム数）、`ExportPanel.tsx`（完了時の長さの表示）である。
- 国名は `textLayout.ts` の `layoutNames` で「、」でつないで折り返している。幅の計測は引数で受け取り、テストでは「1 文字 = 文字サイズ px」のフェイクを使っている。
- 見た目は、承認済みのモック（`.agents/workspace/23/mock.html` 第 4 版）を正とする。

## Goals / Non-Goals

**Goals:**

- モックの配置・動きを Canvas で再現し、プレビューと書き出す動画を同じ見た目にする。
- 「時刻だけから絵が一意に決まる」性質を保つ。
- まとめのページ分け、タグの配置、めくりの長さを単体テストで確かめられるようにする。

**Non-Goals:**

- 地図の描き方（配色・強調・キャッシュ）の変更。地図は描く位置だけを変える。
- コマの間のトランジション。コマの切り替えは今と同じく即時とする（まとめのコマの中のページ送りを除く）。
- PC のコマの一覧の表示内容の変更。

## Decisions

### コマの配置（基準 1080×1920、年のコマとまとめのコマで共通）

| 要素 | 位置 | 内容 |
| --- | --- | --- |
| アプリ名 | y = 150（ベースライン） | 今のまま |
| 年 | 上端 y = 196、高さ 236、x = 80 から 1 桁 132 幅 | 年のコマ：数字ごとのフリップ（210px・800）。まとめ：同じ領域の縦中央に期間（130px・800） |
| 地図 | y = 480、幅 1080 | 今の地図をそのまま描く |
| 国数の行 | 上端 y = 1330 | 左（x = 80）に「累計」と国数、右（x = 560）に「初めて訪れた国」と +N（`--accent-strong`）。間に区切り線（x = 500）。まとめでは右側と区切り線を描かず、ページが複数あれば右端にページの位置（例：1 / 2） |
| 国名 | 上端 y = 1540 | タグ（38px、高さ 68、行間 14）を最大 3 行。幅 920 |
| 進捗バー | y = 1790 | 今のまま |

地図・国数の行・国名の位置を年のコマとまとめのコマで同じ定数にして、コマが切り替わっても配置がずれないようにする。

### 年のフリップの描き方

Canvas には 3D の回転がないため、上下の半分を縦に縮める・伸ばすことでめくりを表す（モックと同じ方法）。

- 1 桁ずつ固定幅のセルの中央に描く。これで等幅数字の指定（Canvas では使えない）なしでも、桁の位置が揺れない。
- 止まっている桁は 1 回で描く。上下に分けて描くと、縮小表示で境目に横線が出るためである（モックの確認で判明した）。
- めくっている桁は「下地に次の数字の上半分と前の数字の下半分」を描き、その上に、めくれる半分を背景色で塗ってから縦に縮めて描く。前半は前の数字の上半分が中央線に向かって縮み、後半は次の数字の下半分が中央線から伸びる。上半分は 1px 長くして下半分に重ね、境目の隙間を防ぐ。めくれる半分は縮むほど文字を暗くする。
- 半分の切り出しには `rect` と `clip` を使う。`FrameContext` に `rect`・`clip` を加える。

### めくりと強調のタイミング

- `timing.ts` に `flipSeconds(timeline, index)` を加える。前の年との差を k 年として `min(0.3 × k, 0.9)` 秒、最初の年は 0 秒。k 回のめくりを均等に割り当てる。
- 年のコマでは、`elapsed - flipSeconds` を起点に、強調（0.6 秒）、累計の数え上げ（0.6 秒）、+N と国名のフェードイン（0.3 秒）を行う。最初の年は、年もフェードインする。
- 地図の強調は強さ 0 でもハイライト色で塗るため、めくっている間はその年の国を強調の対象に渡さず、前の年までの地図を描く。めくり終わった瞬間にその年の国が塗られ、そこから強調色へ変わる。描く絵が違うので、地図のキャッシュのキーもめくっている間（`year-N:flipping`）とその後（`year-N`）で分ける（実機確認で、めくりの途中に地図が先に塗られて見えることが分かったため）。
- 1 年のコマは 2 秒のままなので、めくり（最大 0.9 秒）＋強調（0.6 秒）でも 0.5 秒は止まって見える。

### 国名のタグの配置

`textLayout.ts` の `layoutNames` を、タグを行に詰めて配置する関数に置き換える（「、」の連結は使わなくなるので削除する）。

- タグの幅は「国名の幅 + 左右の余白 44」。行に収まらなければ次の行へ送る。
- 年のコマ：初めて訪れた国のタグ、「再訪」のラベル、再訪した国のタグ（控えめな色）の順に並べ、3 行に収まればそのまま使う。収まらなければ再訪を省き、初めて訪れた国だけを、収まるところまで減らして「ほか N か国」のタグを足す。初めて訪れた国がない年は、「再訪」のラベルと再訪した国を同じ方法で並べる。
- まとめ：すべての国を、3 行に収まる単位で先頭からページに分ける。
- 幅の計測は今と同じく引数で受け取る。

### まとめのページ数をタイミングに渡す

まとめのコマの長さはページ数で決まり、ページ数は文字幅の計測で決まる。タイミングの関数は計測できないため、記録から作ったタイムラインと、計測して分けたページをまとめた `Reel` 型を作り、タイミングとコマの描画はこれを受け取る。

- `buildReel(timeline, measure)` が `{ timeline, summaryPages }` を返す。`measure` は、コマと同じフォント指定を設定した Canvas の `measureText` を使う（`drawFrame.ts` の `createNameTagMeasure()`。Canvas を 1 枚作って使い回す）。
- `totalDuration`・`frameStartTimes`・`frameAt`・`drawFrame`・`exportVideo` は `Timeline` の代わりに `Reel` を受け取る。`PreviewScreen.tsx` で `useMemo` で 1 回作り、書き出しにも同じ `Reel` を渡す。プレビューと書き出しで同じページ分けを使うので、動画の長さとプレビューの再生時間は一致する。
- まとめの長さは `max(4, 2.5 × ページ数)` 秒。ページ i は `2.5 × i` 秒から表示し、最後のページはコマの終わりまで残す。

代替案：国の数で機械的にページを分ける（例：12 か国ずつ）。計測が要らずタイミングが純粋なままになるが、国名の長さによって 3 行からはみ出したり空きが出たりする。表示枠に収まることを優先し、計測で分ける。

### ページの切り替え

- 1 ページ目は、まとめのコマの最初の 0.5 秒でフェードインする（今の一覧のフェードインと同じ）。
- 2 ページ目以降は、ページの頭の 0.4 秒で、前のページが上へ 60 動きながら消え、次のページが下から 60 動きながら現れる。

## Risks / Trade-offs

- [端末のフォントによってページ数が変わり、同じ記録でも端末ごとに動画の長さが違う] → 動画の長さは書き出した端末のプレビューと一致すればよい（`video-export` の要件）。同じ端末では同じ計測を使うので一致する。
- [`Timeline` から `Reel` への引数の変更で、呼び出し元とテストの変更が広がる] → 変更は型で追えるので、型チェックで漏れを見つける。
- [縮小表示で、めくっている間だけ上下の境目がわずかに見える] → 上半分を 1px 重ねて抑える。実機のプレビューで確認する。
- [訪問国が多いと動画が長くなる（例：60 か国で約 5 ページ、まとめだけで約 12.5 秒）] → ユーザーと合意済み。
