# Proposal

## Why

ユーザーが自分の訪問記録を登録する手段がなく、地図にはアプリ同梱のサンプルデータが表示されている（issue #6）。時系列プレビュー（#3）と動画書き出し（#5）はどちらも「いつ・どの国を訪れたか」の記録を前提にしているため、先に記録の入力と保存を用意する。

## What Changes

- 年と国を指定して訪問記録を追加できるようにする。国は日本語名で検索して選ぶ。
- 同じ国を異なる年で複数回登録できるようにする。同じ年・同じ国の組は重複して登録できない。
- 登録した記録を年ごとの一覧で確認し、削除できるようにする。以前の年にも訪れた国には「再訪」と示す。
- 記録は端末のブラウザ内（localStorage）にだけ保存し、再読み込み後も残す。サーバーには送信しない。
- 記録に含まれる国を訪問済みとして地図にハイライトし、訪問国の数を表示する。
- 画面を「記録の画面」として構成する。PC では左に入力欄と一覧のパネル、右に地図を置く。スマートフォンでは上に地図、下に一覧を置き、入力欄は下から出るシートに置く。
- 地図に表示していたサンプルの訪問データを削除する。

## Capabilities

### New Capabilities

- `visit-records`: 訪問記録（年と国の組）の追加・一覧・削除・端末内への保存と、記録から求めた訪問国を地図表示に渡すこと。

### Modified Capabilities

（なし。地図は既存の `world-map` の「訪問済みの国の集合を受け取ってハイライトする」振る舞いをそのまま使い、その集合の作り方は `visit-records` で定める）

## Impact

- `apps/web/src`：訪問記録のデータ処理・保存・国名検索のモジュールと記録画面の UI を追加する。`App.tsx` のレイアウトを変更し、`sampleVisitedCountries.ts` を削除する。
- 国の日本語名は、既存の依存パッケージ `i18n-iso-countries` の日本語データを使う。新しい依存パッケージは追加しない。
- `docs/design-guidelines.md` の「将来の画面の指針 > 記録（#6）」に、承認されたスマートフォンの構成（上に地図、下に一覧、追加はシート）を反映する。
- 時系列アニメーション（#3）は未実装のため、記録をアニメーションに反映するのは #3 で行う。
