# Proposal

## Why

Passport Reel にはまだアプリケーション本体がなく、訪れた国を可視化する機能を載せる土台がない。時系列アニメーション（#3）や訪問データ入力（#6）に先立ち、フロントエンドのみで動くアプリの基盤と「訪問国をハイライトした平面世界地図」を用意する（issue #2）。

## What Changes

- フロントエンドのみで完結する Web アプリのパッケージをワークスペースに追加し、静的ファイルとしてビルドできるようにする。
- 平面の世界地図を描画し、訪問済みの国をハイライト表示する。
- 地図上で判別しにくい小さな国は、マーカーで訪問済みであることを示す。
- 訪問データの入力は別 issue（#6）で扱うため、本変更ではアプリに同梱したサンプルの訪問データを表示する。
- 既存の開発コマンド（`pnpm check`）がアプリパッケージの lint・型検査・テストを含めて通る状態にする。

## Capabilities

### New Capabilities

- `world-map`: 平面の世界地図を表示し、訪問済みの国（ISO 3166-1 alpha-2 で識別）をハイライト・マーカーで示す。

### Modified Capabilities

（なし）

## Impact

- 新規パッケージ `apps/web` を追加し、`pnpm-workspace.yaml`、`vitest.config.ts`（`test.projects`）、`AGENTS.md` と `README.md` の構成説明を更新する。
- 依存パッケージを追加する（ビルドツール、UI フレームワーク、地図描画・国境データ、国コード変換）。
- `.oxlintrc.jsonc` にフレームワーク向けプラグインを追加する。
- サーバーサイドのコンポーネント・外部 API・API キーは導入しない。
