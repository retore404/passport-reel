# Proposal

## Why

コソボは記録できても地図では塗られず、北キプロスとソマリランドは地図に形状があるのに記録の候補に出ない。どの地域を国として扱うかの判断基準もないため、今後地域を足すときに判断がぶれるおそれがある（issue #38）。

## What Changes

- 「入るときに独自のパスポート審査を受ける運用が定着し、事実上認められている地域を国として扱う」という判断基準を、`visit-records` の仕様に書く。あわせて、ISO 3166-1 のコードがない地域に付ける ID のルールと、対象地域の一覧を書く。一覧の正はこの仕様とする。
  - ID は2文字とする。外部で広く使われているコードがあればそれを使い、なければ ISO の利用者割当範囲 `XA`–`XZ` からこのアプリで割り当てる。
  - 一度割り当てた ID は変えず、再利用もしない。保存済みの記録に残っているためである。
- 対象地域として、コソボ（`XK`）、北キプロス（`XN`）、ソマリランド（`XS`）を追加する。
  - 日本語名で検索して訪問記録に追加できる。
  - 記録すると、地図上でその地域がハイライトされる。
  - 北キプロスとソマリランドは、キプロスとソマリアとは別の国として扱う。親国を記録しても塗られず、訪問国数も別々に数える。
- 国コードの表示を変える。ISO 3166-1 の割り当てがない地域は、記録の一覧と国の候補で国コードの代わりに `--` を表示する。ただし、国名データ（i18n-iso-countries）に2文字コードとして収録されている地域はそのコードを表示する（コソボは `XK`）。
- 保存形式（version 1）は変えない。既存の訪問記録は、変更後も同じ内容で表示される。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `visit-records`: 未承認国家を国として扱う判断基準・ID のルール・対象地域の一覧を追加し、国の日本語名検索で対象地域を選べるようにする。記録の一覧で ISO のコードがない地域の国コードの表示を変える。
- `world-map`: 訪問国のハイライトで、対象地域の ID を登録したときにその地域を塗り、親国とは別に扱うことを追加する。

## Impact

- `apps/web/src/records/countryNames.ts`：対象地域を国名の一覧と検索の対象に加え、表示用の国コードを返す。
- `apps/web/src/map/countries.ts`：地図データで ISO の id がない形状に、名前から対象地域の ID を割り当てる。
- `apps/web/src/records/RecordList.tsx`、`RecordForm.tsx`：国コードのバッジを、表示用の国コードにする。
- 対象地域の一覧を1か所に定義し、名前と地図の両方から参照する。
- 「XK は地図に形状がない」ことを前提にしたテスト（`countries.test.ts`、`drawWorldMap.test.ts`、`camera.test.ts`）を書き換える。
- `docs/design-guidelines.md` に、国コードのバッジで `--` を表示することを追記する。
- 新しい依存パッケージや地図データの追加はない。
- 範囲外：形状が親国に含まれているアブハジア・南オセチア・沿ドニエストルは #39 で扱う。地図で塗られないクリスマス島（CX）とココス諸島（CC）も今回は扱わない。
