# Spec Delta

## ADDED Requirements

### Requirement: 同じ年の中の訪問順
システムは、同じ年の記録について、その年の中で訪れた順番を持たなければならない（SHALL）。新しく追加した記録は、その年の最後に訪れたものとして扱わなければならない（SHALL）。訪問順は端末のブラウザ内に記録と一緒に保存し、ページを再読み込みしても復元しなければならない（SHALL）。訪問順を持つ前に保存された記録は、追加した順を訪問順として扱わなければならない（SHALL）。

#### Scenario: 追加した記録はその年の最後に入る
- **WHEN** 2019 年にフランス、イタリアの記録がある状態で、2019 年・スペインを追加する
- **THEN** 2019 年の訪問順はフランス、イタリア、スペインになる

#### Scenario: 訪問順が保存される
- **WHEN** 2019 年の訪問順をイタリア、フランスに並べ替えてからページを再読み込みする
- **THEN** 2019 年の訪問順はイタリア、フランスのままである

#### Scenario: 以前から保存されている記録
- **WHEN** 訪問順を扱う前のアプリで 2019 年にフランス、イタリアの順で追加した記録がある状態で、アプリを開く
- **THEN** 2019 年の訪問順はフランス、イタリアになる

### Requirement: 訪問順の並べ替え
システムは、記録の一覧で、同じ年の記録をドラッグ＆ドロップで並べ替えて訪問順を変えられなければならない（SHALL）。マウスとタッチのどちらでも並べ替えられなければならず（SHALL）、キーボードだけでも並べ替えられなければならない（SHALL）。記録を別の年へ移してはならない（MUST NOT）。

#### Scenario: ドラッグで並べ替える
- **WHEN** 2019 年にフランス、イタリアの順の記録がある状態で、イタリアをフランスの上へドラッグして離す
- **THEN** 2019 年の訪問順はイタリア、フランスになる

#### Scenario: スマートフォンで並べ替える
- **WHEN** スマートフォンのブラウザで、記録の一覧の記録をタッチ操作でドラッグして同じ年の別の位置で離す
- **THEN** その位置に記録が移り、訪問順が変わる

#### Scenario: キーボードで並べ替える
- **WHEN** キーボードだけを使って、2019 年のイタリアを 1 つ前へ移す操作をする
- **THEN** 2019 年の訪問順はイタリア、フランスになる

#### Scenario: 別の年へは移せない
- **WHEN** 2019 年のフランスを 2016 年の記録の間へドラッグして離す
- **THEN** フランスは 2019 年の記録のままで、2016 年の記録は変わらない

## MODIFIED Requirements

### Requirement: 訪問記録の一覧
システムは、登録された記録を年ごとにまとめ、新しい年を上にして一覧表示しなければならない（SHALL）。同じ年の記録は、その年の訪問順に上から並べなければならない（SHALL）。各記録には国名と国コードを表示しなければならない（SHALL）。より前の年にも同じ国の記録がある記録には、再訪であることを示さなければならない（SHALL）。

#### Scenario: 年ごとに新しい順で並ぶ
- **WHEN** 2016 年と 2024 年の記録がある
- **THEN** 一覧では 2024 年のまとまりが 2016 年のまとまりより上に表示される

#### Scenario: 年の中は訪問順に並ぶ
- **WHEN** 2019 年の訪問順がイタリア、フランスである
- **THEN** 一覧の 2019 年のまとまりでは、イタリアがフランスより上に表示される

#### Scenario: 再訪が示される
- **WHEN** 2016 年・日本と 2024 年・日本の記録がある
- **THEN** 2024 年の日本の記録に再訪の表示が付き、2016 年の日本の記録には付かない

#### Scenario: 記録がない
- **WHEN** 記録が 1 件もない
- **THEN** 一覧には記録がないことと、追加の方法が示される
