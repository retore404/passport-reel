# Design

## Context

- 訪問記録は `VisitRecord { year, country }` の配列で、ID を持たない。配列は追加した順に並び、`storage.ts` は version 1 の形式でその配列をそのまま保存・復元する。`groupByYear` も年の中の並びを保つ。
- 年ごとの表示は `buildTimeline` → `buildReel`（まとめのページ分け）→ `timing.ts`（`totalDuration`・`frameAt`・`frameJumpTimes`）→ `drawFrame` の流れで、プレビュー（`PreviewScreen.tsx`）と書き出し（`exportVideo.ts`・`useVideoExport.ts`・`ExportPanel.tsx`）が同じ `Reel` を使う。
- 国名は `timeline.ts` で日本語名順に並べている。
- 地図は `mapLayers.ts` が固定の投影で描いた絵をオフスクリーンにキャッシュし、`drawImage` で貼っている。50m の地図を毎フレーム描くとスマートフォンで重いためである。
- テストは DOM のない環境で動き、Canvas は記録用のフェイクで置き換えている。`Path2D` や `document` に触れる処理は `mapLayers.ts` のような DOM 側の層に閉じ込めている。
- 見た目は承認済みのモックを正とする。1 か国ずつの表示のコマは `.agents/workspace/40/mock.html`（claude.ai の Artifact 第 5 版と同じ内容）、プレビューのモード切り替えは `.agents/workspace/40/mode-switch-mock.html` の案2。

## Goals / Non-Goals

**Goals:**

- 訪問順を既存の保存形式のまま扱い、移行なしで導入する。
- 新しい表示モードでも「時刻だけから絵が一意に決まる」性質を保ち、プレビューと書き出す動画を同じ見た目にする。
- 寄せる位置・大きさ、移動の補間、日付変更線の扱い、タグの押し出しを、DOM なしの純粋な関数として単体テストできるようにする。

**Non-Goals:**

- 年ごとの表示のコマの配置・動き・地図の描き方の変更（国名の並び順だけを変える）。
- 表示モードの選択を端末に保存すること。プレビューを開くたびに「1 か国ずつ」から始める。
- 訪問の日付や月の記録。
- プレビューの描画性能の先回りの最適化。実装後に実機で確かめ、重ければ対処する（Risks を参照）。

## Decisions

### 訪問順は配列の並びで表す

同じ年の中の訪問順は「記録の配列の中で、同じ年の記録が並ぶ順」とする。

- `visitRecords.ts` に、同じ年の中で記録を別の位置へ移した新しい配列を返す純粋な関数を加える。年をまたぐ移動は受け付けず、元の配列を返す。
- `addRecord` は配列の末尾に足すので、そのままで「その年の最後」になる。
- `storage.ts` の形式（version 1）は変えない。既存の保存データは追加した順がそのまま訪問順になり、仕様の「以前から保存されている記録」を移行なしで満たす。古いアプリで開いても同じデータを読める。
- 代替案：記録に `order` の数値を持たせる案は、保存形式の版上げと読み替えが要り、配列の並びと二重管理になるので採らない。

### 並べ替えは dnd-kit を使う

`@dnd-kit/core` と `@dnd-kit/sortable`（と `@dnd-kit/utilities`）を依存に加え、版は固定する。

- 年ごとに `SortableContext` を分けて、記録を別の年へ移せないようにする。
- 各行の左端にドラッグ用のつまみ（グリップ）を置き、そこからだけドラッグを始める。行全体をつまみにすると、一覧のスクロールや削除ボタンの操作とぶつかるためである。
- ポインタ（マウス・タッチ）にはわずかな移動量の起動条件を付け、タップと区別する。キーボードは dnd-kit のキーボード操作（つまみにフォーカス → Space で持ち上げ → 矢印で移動 → Space で確定、Esc で取り消し）を使い、読み上げの文言は日本語にする。
- 代替案：
  - HTML5 のドラッグ＆ドロップ API は、iOS Safari のタッチ操作が不安定で、キーボード操作もないため採らない。
  - ポインタイベントで自作する案は、スクロールとの干渉、長押し、読み上げまで作ると量が多く、保守の負担に見合わないため採らない。
- 第三者ライセンスの一覧は Vite の `build.license` がビルド時に集めるので、追加の作業は要らない。

### 国名の並び順（年ごとの表示）

`buildTimeline` の日本語名順の並べ替え（`byJapaneseName`）をやめる。

- 年のコマの「初めて訪れた国」と「再訪した国」は、それぞれその年の訪問順に並べる。
- まとめの国名は、初めて訪れた順に並べる。両方の表示モードで同じ並びを使う。

### 表示モードを Reel に持たせる

`Reel` を、表示モードごとの内容を持つ判別可能な共用体にする（`mode: "year" | "focus"`）。

- `timing.ts` の `totalDuration`・`frameAt`・`frameJumpTimes`、`frameList.ts`、`drawFrame` は `Reel` のモードで分岐する。書き出し側は `Reel` を受け取るだけなので、選んだモードのまま書き出せる。
- まとめのページ分け（`summaryPages`）と、まとめのコマの長さの規則は両モードで共通にする。
- 1 か国ずつの表示の内容は、記録から作る「訪問の並び」とする。各訪問に、年、国、初めて訪れたか、初めて訪れた国の連番、訪問前後の累計、カメラの目標を持たせる。
- 代替案：モードごとに別の再生系（別の `timing`・別のプレイヤー）を作る案は、プレビューの操作と書き出しを二重に持つことになるため採らない。

### タイミング（1 か国ずつの表示）

| 区間（訪問のコマの頭からの秒） | 動き |
| --- | --- |
| 0.0–0.6 | 前の国から移動して寄る（遠いときは途中で引く）。年が変わる訪問は 0.0–0.45 で年を切り替える |
| 0.55–0.85 | 「#N」と国名（再訪なら「再訪」のタグ）がフェードインしながら左から入る |
| 0.9–1.5 | その国を強調色で塗り、累計を数え上げ、初めて訪れた国ならタグを末尾に加える |
| 1.5–1.6 | 止まって見せる |

- まとめのコマは、頭の 1.0 秒で世界全体まで引き、続いて期間と国名のタグをフェードインする。長さは年ごとの表示と同じ規則（最低 4 秒、複数ページなら 1 ページ 2.5 秒 × ページ数）。
- コマの一覧で選んだときの移動先は、訪問のコマでは 1.5 秒の時点、まとめでは年ごとの表示と同じ考え方の時点とする。

### カメラ

地図の座標は、今の世界地図の投影（幅 1080 に世界全体を収めたメルカトル）で投影した平面の座標（以下、世界座標）を使う。カメラは「世界座標の注視点 (x, y)、拡大率 k、注視点を置く画面上の位置 (sx, sy)」で表し、画面上の点は `(sx, sy) + (p − (x, y)) × k` で決める。

- **寄せる目標**：国の最も大きいポリゴンの外接矩形の中心を注視点にする（フランス本土、アメリカ本土を選ぶため）。k は外接矩形が 900×600 の枠の 6 割に収まる値とし、1.8〜16 に丸める。注視点は画面の (540, 820) に置く。
- **世界全体**：k = 1 で、地図が年ごとの表示と同じ位置（y = 480 から）に来るようにする。最初の訪問の移動元とまとめの移動先に使う。
- **移動の補間**：注視点と画面上の位置は ease-in-out で線形に補間する。拡大率は対数で補間し、移動距離に比例する量だけ途中で引く（`log k = 補間値 − dip × sin(πt)`）。d3-interpolate の `interpolateZoom` は依存を増やすほどの差がないので使わない。
- **日付変更線**：世界座標は横方向に幅 W（1080）で繰り返すとみなす。訪問の並びを作るときに、各訪問の目標の x を「x、x + W、x − W のうち前の訪問の目標に最も近いもの」に置き換え、x を連続した値として持つ。これで移動は常に短い方向になり、時刻だけからカメラが決まる性質も保てる。描くときは、画面に入る範囲で地図を左右にずらして重ねて描く。

カメラの計算（目標、補間、x の繰り返しの扱い）はすべて DOM なしの純粋な関数にして、単体テストで確かめる。

### 寄せた地図の描き方

固定の絵を貼る今のキャッシュは、拡大するとぼやけるので使えない。1 か国ずつの表示用に、地図の描画層を加える。

- 国ごとの形を、世界座標で `Path2D` として 1 回だけ作って持つ。毎フレームは Canvas の変換（平行移動・拡大）を設定して `Path2D` を塗るだけにし、投影の計算を繰り返さない。線の太さは k で割って見た目の太さをそろえる。
- 外接矩形が画面の外にある国は描かない。
- その訪問の国は最後に描き、強調色と光彩を付ける。移動が終わる頃に、国の位置を示す輪を一度広げる。
- まとめのコマで世界全体まで引き終わった後は、年ごとの表示と同じ `mapLayers` の描き方（小さな国のマーカーを含む）に切り替え、まとめのコマの絵を年ごとの表示とそろえる。
- この層は `mapLayers.ts` と同じく DOM 側に置き、コマの描画からは型だけを使ってテストではフェイクに置き換える。

### コマの配置（1 か国ずつの表示、基準 1080×1920）

| 要素 | 位置 | 内容 |
| --- | --- | --- |
| 地図 | 画面全体 | カメラで寄せた地図 |
| ぼかし | 上：0〜470、下：1250〜1920 | 文字を読みやすくする背景色のグラデーション。地図が下端まで見える程度に薄くする（上は最大 0.8、下は最大 0.55）。まとめのコマで引くにつれて消す |
| アプリ名 | 年ごとの表示と同じ | 今のまま |
| 年 | x = 80、縦の中央 y = 314 | 150px・800。年が変わる訪問では、前の年が上へ抜け、次の年が下から入る。まとめでは同じ位置に期間（年ごとの表示と同じ 130px） |
| 番号 | ベースライン y = 1062 | 「#N」36px・`--muted`。初めて訪れた国だけ |
| 国名 | ベースライン y = 1190 | 120px・800。幅に収まらなければ縮める。再訪なら右に枠線だけの「再訪」タグ（今の再訪タグと同じ見た目）。読みやすさのため文字に暗い影を付ける |
| 累計 | 年ごとの表示の国数の行と同じ | 左の累計だけを描く（右の +N と区切り線は描かない） |
| 国名のタグ | 年ごとの表示の国名と同じ | 初めて訪れた国のタグ。地図に重なるので、地は `--surface-2` を半透明にする。今の国のタグは強調色で加わる |
| 進捗バー | 年ごとの表示と同じ | 今のまま |

### タグの押し出し

タグは「初めて訪れた順の国名のうち、末尾から数えて 3 行に収まる分」を表示する。

- 配置は、末尾のタグから逆向きに詰めて 3 行に収まる数を求め、その分を先頭から並べ直して決める。年ごとの表示のタグと同じ寸法・行の詰め方を使う。
- 新しいタグが加わる区間（0.9–1.5 秒）では、加わる前と後の配置を補間する。残るタグは前の位置から後の位置へ滑らかに動き、押し出されるタグはフェードアウトし、新しいタグはフェードインする。
- 配置の計算は純粋な関数にして、押し出される数をテストで確かめる。

### プレビューのモード切り替え

- 「1 か国ずつ」「年ごと」の 2 つのボタンからなる切り替え（既定の「1 か国ずつ」を左）を、操作の側に置く（承認済みのモック `.agents/workspace/40/mode-switch-mock.html` の案2）。
  - PC：右のパネルの先頭に見出し「表示」と切り替えを置き、その下に今の「コマ」の一覧を続ける。切り替えはパネルの横幅いっぱいにし、2 つのボタンを同じ幅にする。
  - スマートフォン：再生の操作の並びの 1 行目に、切り替えを横幅いっぱいで置き、2 行目以降に今の操作（最初から再生、再生・停止、再生位置、時間、書き出す）を並べる。
  - 見た目は、PC の上部バーの「記録／プレビュー」の切り替え（`.view-switch`）と同じにする。選択中のボタンは `aria-pressed` で示す。
  - 代替案：プレビューの真上に置く案（モックの案1）は、プレビューが小さくなるため採らない。
- 切り替えたら再生を止めて時刻 0 に戻し、再生位置のバーとコマの一覧を新しい `Reel` に合わせる。
- 書き出し中は切り替えを無効にする。書き出し中に `Reel` が変わると、書き出している内容と画面が食い違うためである。
- PC のコマの一覧は、1 か国ずつの表示では訪問ごとの項目を並べる。項目の文字は「#N 国名」（再訪は「国名 再訪」）、右の欄は年とする。

## Risks / Trade-offs

- [寄せた地図を毎フレーム描くため、スマートフォンのプレビューでコマ落ちするおそれがある] → 実装後に実機で確かめる。重い場合は、移動中だけ粗い地図（110m）にする、プレビューの内部解像度を下げる、のどちらかで対処する。書き出しは 1 フレームずつ描くので、重くてもコマ落ちしない。
- [訪問が多いと動画が長くなる（1 訪問 1.6 秒で固定）] → 合意済みの仕様として受け入れる。
- [dnd-kit の依存が増える] → 版を固定し、Renovate で更新を追う。並べ替えの処理は `visitRecords.ts` の純粋な関数に置き、ライブラリには画面の操作だけを任せる。
- [国名が長い国やタグの多い年で、地図の上の文字が読みにくくなる] → 国名は幅に合わせて縮め、文字には影、タグには半透明の地を付ける。
- [まとめで、寄せた地図の描き方から `mapLayers` の描き方へ切り替える瞬間に、小さな国のマーカーが急に現れる] → 切り替えは引き終わった時点（k = 1）で行い、マーカーはフェードインさせる。

## Migration Plan

- 保存形式は変えないので、データの移行は要らない。既存の記録は追加した順が訪問順になる。
- 戻す場合も、保存データは以前のアプリでそのまま読める（並べ替えた順番は、以前のアプリでは単に配列の並びとして残る）。

## Open Questions

- 移動の補間の具体的な係数（引く量、ease の形）は、モックの値を出発点に実装時に見た目で調整する。
