# Design

## Context

- 地図の形状は `map/countries.ts` の `toMapCountries` が world-atlas 2.0.2（countries-50m）から作る。world-atlas の元データは Natural Earth 4.1.0 の 1:50m。ジョージア（id 268）とモルドバ（id 498）は、どちらも穴のない1つのポリゴンで、3地域を含んでいる。
- #38 の地域（XK・XN・XS）は world-atlas に単独の形状があるので、`records/unrecognizedStates.ts` の `mapName` で形状を名前で引いている。海外領土は `splitOverseasTerritories` が親国の MultiPolygon から島単位のポリゴンを振り分けている。今回の3地域は本土と地続きなので、どちらの方法も使えない。
- 1か国ずつの表示の寄せる範囲（`timeline/mapLayers.ts` の `focusBoundsByCountry`）、強調（`drawEmphasizedCountries`）、マーカーの判定（`planWorldMap`）は、どれも `MapCountry` の一覧から国ごとの形状を引いている。そのため、一覧の段階で親国を分ければ、すべてに反映される。
- explore での検証の結果は次のとおり。
  - Natural Earth の `ne_50m_admin_0_breakaway_disputed_areas`（v5.1.2。形状は 4.1.0 と同じ）にある Abkhazia・South Ossetia・Transnistria は、外周が「親国の外周の連続した1区間」と「親国の内側を通る境界線」からできている。
  - 共有する区間の頂点は world-atlas の頂点と1対1に対応する。ずれは最大 0.0019 度（world-atlas の量子化による誤差）。
  - 親国の外側にはみ出す頂点はない。アブハジアと南オセチアの区間は重ならない。

## Goals / Non-Goals

**Goals:**

- ジョージア・モルドバを、地域を除いた残りの部分と地域とに、隙間も重なりもなく分ける。
- world-atlas を更新して分けられなくなったときに、テストで気づけるようにする。

**Non-Goals:**

- 汎用のポリゴン演算（差・交差）。今回の形状の関係では要らない（Decisions を参照）。
- 境界線を抜き出すスクリプトをリポジトリに置くこと。抜き出しは一度きりなので、手順はデータのコメントに残す。
- ほかの係争地（Natural Earth の同じデータにある残りの25件）の扱い。

## Decisions

### 形状の出典は Natural Earth 1:50m の係争地データにする

world-atlas と同じ Natural Earth の同じ縮尺なので、国境の頂点が対応する。Natural Earth はパブリックドメインで、帰属表示は求められていない。

- 代案：OpenStreetMap の行政境界。精度は高いが world-atlas の国境と合わず、隙間や重なりが出る。ODbL の帰属表示も必要になる。
- 代案：Natural Earth のデータを含む npm パッケージを足す。3地域のために依存を増やすことになり、中身の版も管理しにくい。
- 代案：world-atlas の 10m 版。国の形状しかなく、3地域の形状はない。

### 同梱するのは境界線だけにし、読み込むときに親国を分ける

地域ごとに、親国の内側を通る境界線の頂点の並びだけを持つ。線の両端は world-atlas の頂点の座標と完全に同じ値にする。読み込むときに、親国の外周から両端の頂点を探し、外周を2つに分ける。

```
  親国の外周  ... [A ======== B] ...      A・B = 境界線の両端（world-atlas の頂点）
                   | 共有区間  |
                   +--境界線---+

  地域   = 外周の A..B の区間 + 境界線（B -> A）
  親国' = 外周の残り（B..A）+ 境界線（A -> B）
```

- 共有区間は world-atlas の座標をそのまま使うので、分けた2つの形状は境界線も外周も同じ頂点を共有する。隙間も重なりも生まれない。
- ジョージアは2地域を順に分ける（アブハジアを分けた残りから、さらに南オセチアを分ける）。
- 分けた後の形状の外周の向きは、親国の外周の向きに合わせる。d3-geo は外周の向きで内側を決めるため、向きが逆だと地球全体を塗ってしまう。
- 代案：分けた後の完成品（地域の形状と、切り抜いた後の親国の形状）を事前に計算して同梱する。world-atlas の親国の形状の写しを持つことになり、world-atlas を更新すると写しが古いまま残る。
- 代案：Natural Earth の地域のポリゴンをそのまま持ち、汎用の差の計算で親国から抜く。頂点が最大 0.0019 度ずれているため、親国の側に幅 200m 以下の細い切れ端が別のポリゴンとして残る。親国の範囲が地域の端まで広がってしまうので、寄せる範囲がずれる。ポリゴン演算の依存も増える。
- 代案：親国の上に地域を重ねて描く。強調では親国を上から描き重ねるので地域まで光り、寄せる範囲にも地域が入る。

### 境界線のデータは `map/` に置き、地域の一覧からは「どの親国を分けるか」を参照する

一覧の正は visit-records の仕様なので、地域の一覧は引き続き `records/unrecognizedStates.ts` に置く。各地域の「地図での形状の見つけ方」を2種類にする。

- 単独の形状の名前（既存の `mapName`）
- 分ける親国の ISO 3166-1 alpha-2（`GE`・`MD`）

境界線の座標は地図だけが使うデータなので、`map/` の新しいモジュールに、地域の ID をキーにして置く。そのモジュールのコメントには次のことを書く。

- 出典（Natural Earth の版とファイル名）
- 抜き出し方：地域のポリゴンから、親国の国境から 0.01 度以上離れた頂点を取り出し、その両隣の国境上の頂点を world-atlas の最も近い頂点に合わせて両端にする

`toMapCountries` は、親国の id を alpha-2 にしてから、その国を分ける地域があれば分ける。海外領土の切り出しと同じく、国ごとの変換の中で行う。

- 代案：境界線の座標も `records/unrecognizedStates.ts` に持つ。記録の側に地図の座標が入り込むので、責務が混ざる。

### 分けた地域の形状には親国の id と名前を引き継がない

海外領土と同じく、地域の形状は `id` を持たず、`properties` も空にする。親国の名前で地域を引いてしまわないようにするためである。テストでは `alpha2` で形状を引く。

### 別名は既存の `COUNTRY_ALIASES` に足す

南オセチアに「ミナミオセチア」、沿ドニエストルに「エンドニエストル」「トランスニストリア」を足す。アブハジアはカタカナだけの名前なので、部分一致で引ける。

## Risks / Trade-offs

- [world-atlas を更新すると両端の頂点が見つからず、地域が分けられなくなる] → 各地域について「両端が親国の外周にちょうど1回ずつあり、分けた後の地域と親国がどちらも1つ以上のポリゴンを持つ」ことを単体テストで確かめる。読み込むときに両端が見つからない場合は、親国を分けずにそのまま使い、表示を中断しない（地域はどの形状にも対応しないコードとして扱われる）。
- [外周の向きを誤ると、地域か親国が地球全体を塗る] → 分けた後の各形状の球面上の面積が、親国の面積より小さく、合計が親国の面積と一致することを単体テストで確かめる。
- [境界線の座標は手作業で抜き出すので、誤りに気づきにくい] → 「境界線の頂点がすべて親国の内側にある」ことを単体テストで確かめる。描画の確認では、分けた境界に隙間がないことを見る。
- [同梱するデータ] → 境界線の頂点は3地域で計 95 個ほど、数 KB で、地図の読み込みの大きさにほぼ影響しない。

## Migration Plan

保存形式は変えないので、データの移行は必要ない。元に戻す場合も保存データには触れないので、XA・XO・XT の記録は、名前と地図に対応しないコードとして残る（地図に存在しない国コードの扱いの要件により、表示は中断しない）。
