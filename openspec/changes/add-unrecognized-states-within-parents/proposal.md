# Proposal

## Why

#38 で定めた判断基準に当てはまるアブハジア・南オセチア・沿ドニエストルは、地図データ（world-atlas）に単独の形状がなく、ジョージア・モルドバの形状に含まれている。そのため、訪問しても記録や地図に反映できない（issue #39）。

## What Changes

- `visit-records` の「国として扱う ISO 3166-1 にない地域」の一覧に、次の3地域を追加する。ID は既存のルールに従い、外部で広く使われている2文字のコードがないため、利用者割当範囲 `XA`–`XZ` から英語名の頭文字で割り当てる。
  - `XA` アブハジア（Abkhazia）
  - `XO` 南オセチア（South Ossetia。`XS` は使用済み）
  - `XT` 沿ドニエストル（Transnistria）
- 3地域を日本語名で検索して訪問記録に追加できるようにする。漢字で始まる名前を読みで引けるよう、別名「ミナミオセチア」「エンドニエストル」と、英語由来の呼び名「トランスニストリア」を足す。国コードの表示は、3地域とも国名データにコードがないため `--` とする。
- 地図では、ジョージア・モルドバの形状を地域との境界線で分け、3地域を親国とは別の国として扱う。
  - 地域の ID を記録すると、その地域が塗られる。
  - 親国を記録しても地域は塗られない。地域を記録しても親国は塗られない。
  - 親国の範囲（1か国ずつ寄るときの範囲、強調表示、小さな国のマーカーの判定）に地域を含めない。
  - 訪問国数は親国と地域を別々に数える。
- 境界線は Natural Earth（パブリックドメイン）の 1:50m の係争地データから抜き出し、アプリに同梱する。地図の表示に外部への通信は追加しない。
- 一覧表の「地図データでの形状」の列を、親国を分けて作る地域も書けるように改める。
- 保存形式（version 1）は変えない。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `visit-records`: 「国として扱う ISO 3166-1 にない地域」の一覧に XA・XO・XT を追加し、地図での形状の書き方を改める。読みで検索するシナリオと、親国と別に数えるシナリオを足す。
- `world-map`: 訪問国のハイライトで、親国の形状に含まれる ISO 3166-1 にない地域（XA・XO・XT）を親国から分けて塗り、親国とは別の国として扱うことを追加する。

## Impact

- `apps/web/src/records/unrecognizedStates.ts`：3地域を一覧に加える。形状の見つけ方に「親国を境界線で分ける」種類を足す。
- `apps/web/src/records/countryNames.ts`：別名を足す。
- `apps/web/src/map/countries.ts`：読み込むときに、ジョージア・モルドバの形状を境界線で分ける。
- 新しく、境界線のデータ（Natural Earth から抜き出したもの）を同梱する。新しい依存パッケージは足さない。
- テスト：`countries.test.ts`、`countryNames.test.ts`、`unrecognizedStates.test.ts` に、分け方と検索のテストを足す。
- 範囲外：地図で塗られないクリスマス島（CX）とココス諸島（CC）は今回も扱わない。
