# world-map Specification

## Purpose

訪問済みの国を平面の世界地図上で一目で分かるように示す。時系列アニメーションや動画書き出しが共通して使う地図表示の振る舞いを定める。

## Requirements

### Requirement: 平面世界地図の表示
システムは、ブラウザでアプリを開いたとき、全世界の国境を含む平面の世界地図を表示しなければならない（SHALL）。地図の表示にサーバーサイドの処理や外部 API への通信を必要としてはならない（MUST NOT）。

#### Scenario: アプリを開くと世界地図が表示される
- **WHEN** ユーザーがビルド済みのアプリをブラウザで開く
- **THEN** 平面の世界地図が国境線付きで表示される

#### Scenario: 外部通信なしで表示される
- **WHEN** アプリの配信元以外へのネットワーク通信が遮断された環境でアプリを開く
- **THEN** 世界地図が表示される

### Requirement: 訪問国のハイライト
システムは、訪問済みの国の集合（ISO 3166-1 alpha-2 コード、または visit-records の「国として扱う ISO 3166-1 にない地域」で定める地域の ID）を受け取り、該当する国を未訪問の国と区別できる色で塗らなければならない（SHALL）。国境データで親国の形状に含まれる海外領土（フランスの GF・GP・MQ・YT・RE、ノルウェーの SJ、オランダの BQ）は、親国とは別の国として扱い、親国を登録しても塗ってはならず（MUST NOT）、海外領土のコードを登録したときにその地域を塗らなければならない（SHALL）。「国として扱う ISO 3166-1 にない地域」のうち国境データに単独の形状がある地域（XK・XN・XS）は、その ID を登録したときにその地域を塗り、親国とは別の国として扱わなければならない（SHALL）。国境データで親国の形状に含まれている地域（ジョージアの XA・XO、モルドバの XT）も、その ID を登録したときにその地域を塗り、親国とは別の国として扱わなければならない（SHALL）。

#### Scenario: 訪問国が塗り分けられる
- **WHEN** 訪問済みの国の集合に `JP` と `FR` が含まれる
- **THEN** 日本とフランスがハイライト色で塗られ、それ以外の国は未訪問の色で塗られる

#### Scenario: 訪問国がない
- **WHEN** 訪問済みの国の集合が空である
- **THEN** すべての国が未訪問の色で塗られる

#### Scenario: 親国を登録しても海外領土は塗られない
- **WHEN** 訪問済みの国の集合に `FR` が含まれ、`GF` が含まれない
- **THEN** フランス本土とコルシカが塗られ、フランス領ギアナは未訪問の色で塗られる

#### Scenario: 海外領土を登録するとその地域が塗られる
- **WHEN** 訪問済みの国の集合に `GF` が含まれ、`FR` が含まれない
- **THEN** フランス領ギアナが塗られ、フランス本土は未訪問の色で塗られる

#### Scenario: 小さな海外領土にマーカーが出る
- **WHEN** 訪問済みの国の集合に `GP`（グアドループ）が含まれる
- **THEN** グアドループの位置にマーカーが表示される

#### Scenario: ISO 3166-1 にない地域を登録するとその地域が塗られる
- **WHEN** 訪問済みの国の集合に `XK`、`XN`、`XS` が含まれる
- **THEN** コソボ、北キプロス、ソマリランドがハイライト色で塗られる

#### Scenario: 親国を登録しても ISO 3166-1 にない地域は塗られない
- **WHEN** 訪問済みの国の集合に `CY` と `SO` が含まれ、`XN` と `XS` が含まれない
- **THEN** キプロスとソマリアが塗られ、北キプロスとソマリランドは未訪問の色で塗られる

#### Scenario: ISO 3166-1 にない地域を登録しても親国は塗られない
- **WHEN** 訪問済みの国の集合に `XN` と `XS` が含まれ、`CY` と `SO` が含まれない
- **THEN** 北キプロスとソマリランドが塗られ、キプロスとソマリアは未訪問の色で塗られる

#### Scenario: 親国の形状に含まれていた地域を登録するとその地域が塗られる
- **WHEN** 訪問済みの国の集合に `XA`、`XO`、`XT` が含まれ、`GE` と `MD` が含まれない
- **THEN** アブハジア、南オセチア、沿ドニエストルがハイライト色で塗られ、ジョージアとモルドバの残りの部分は未訪問の色で塗られる

#### Scenario: 親国を登録しても親国の形状に含まれていた地域は塗られない
- **WHEN** 訪問済みの国の集合に `GE` と `MD` が含まれ、`XA`、`XO`、`XT` が含まれない
- **THEN** ジョージアとモルドバが塗られ、アブハジア、南オセチア、沿ドニエストルは未訪問の色で塗られる

### Requirement: 小さな国のマーカー表示
システムは、表示中の地図上で面として判別しにくい大きさの訪問国について、その国の位置にマーカーを表示し、訪問済みであることを視認できるようにしなければならない（SHALL）。未訪問の小さな国にはマーカーを表示してはならない（MUST NOT）。

#### Scenario: 小さな訪問国にマーカーが出る
- **WHEN** 訪問済みの国の集合に `SG`（シンガポール）が含まれる
- **THEN** シンガポールの位置にマーカーが表示される

#### Scenario: 大きな訪問国にはマーカーが出ない
- **WHEN** 訪問済みの国の集合に `FR` が含まれる
- **THEN** フランスは面のハイライトで示され、マーカーは表示されない

#### Scenario: 未訪問の小さな国にはマーカーが出ない
- **WHEN** 訪問済みの国の集合に `SG` が含まれない
- **THEN** シンガポールの位置にマーカーは表示されない

### Requirement: 地図に存在しない国コードの扱い
システムは、訪問済みの国の集合に地図上の国と対応しないコードが含まれていても、表示を中断せず、対応する国のハイライトを続けなければならない（SHALL）。

#### Scenario: 未知のコードが混在する
- **WHEN** 訪問済みの国の集合が `JP` と、地図上に対応する国がないコードを含む
- **THEN** 日本はハイライトされ、地図は正常に表示される

### Requirement: 親国の形状に含まれる地域の切り分け
システムは、国境データで親国の形状に含まれている「国として扱う ISO 3166-1 にない地域」（XA・XO・XT）について、親国の形状をその地域との境界線で分け、地図のどの表示でも親国の範囲にその地域を含めてはならない（MUST NOT）。塗り、その年に初めて訪れた国の強調、1 か国ずつの表示で国へ寄せる範囲、小さな国のマーカーの判定は、いずれも地域を除いた親国の範囲を使わなければならない（SHALL）。境界線のデータはアプリに同梱し、地図の表示に外部への通信を追加してはならない（MUST NOT）。分けた後の親国と地域の間に、隙間や重なりが見えてはならない（MUST NOT）。

#### Scenario: 親国を強調しても地域は強調されない
- **WHEN** 2024 年に初めて訪れた国がジョージアだけで、アブハジアは訪れていない
- **THEN** 2024 年のコマの地図で、ジョージアの残りの部分が強調色で塗られ、アブハジアと南オセチアは強調されない

#### Scenario: 親国へ寄せる範囲に地域が含まれない
- **WHEN** 1 か国ずつの表示で、ジョージアの訪問のコマになる
- **THEN** 地図はアブハジアと南オセチアを除いたジョージアの範囲に合わせて寄せられる

#### Scenario: 地域へ寄せる
- **WHEN** 1 か国ずつの表示で、沿ドニエストルの訪問のコマになる
- **THEN** 地図は沿ドニエストルの範囲に合わせて寄せられる

#### Scenario: 分けた境界に隙間が出ない
- **WHEN** 訪問済みの国の集合に `GE` と `XA` が含まれる
- **THEN** ジョージアとアブハジアがハイライト色で塗られ、2つの間に未訪問の色や海の色の隙間は見えない

#### Scenario: 外部通信なしで地域が表示される
- **WHEN** アプリの配信元以外へのネットワーク通信が遮断された環境で、訪問済みの国の集合に `XA` が含まれる状態の地図を表示する
- **THEN** アブハジアがハイライト色で塗られる
