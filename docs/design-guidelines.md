# デザインガイドライン

Passport Reel の見た目の方針。画面を追加・変更するときはこの文書に従い、方針そのものを変えるときはこの文書も更新する。

## 基本方針

- **地図が主役。** 地図は表示領域いっぱいに置き、枠やカードで囲まない。操作部品は地図の上に浮かせるか、パネル・シートに置く。
- **暗い配色。** 背景は青みのある黒にし、海の色を背景と同じにして地図の境目を見せない。
- **色は訪問国のために取っておく。** 未訪問の国や UI の地は彩度を抑え、アクセント色（琥珀色）は訪問国・主要ボタン・強調する数字にだけ使う。
- **動画で見栄えすること。** 動画は 9:16 を基準にし、画面上のプレビューと書き出す動画が同じ見た目になるようにする。

### 根拠（類似アプリの調査）

| アプリ | 参考にした点 |
| --- | --- |
| Visited、World Map: Visited Countries | 地図を画面いっぱいに置き、訪問国だけをはっきりした1色で塗る。操作はタブと下から出るシートにまとめる |
| Polarsteps | 地図を全画面に置き、タイトルや操作を地図の上に重ねる。詳細は下から出るシートで見せる |
| Mult.dev | 動画の地図スタイルに Light／Gray／Day／Night の4種類があり、Night は暗い背景に塗り分けた国を置く。スマートフォンでは上にプレビュー、下に設定シートを置く |
| Been | 余計な装飾がない、数値中心の簡潔な UI |

## デザイントークン

CSS 変数として `apps/web/src/index.css` の `:root` に定義している。新しい色や角丸を直接書かず、まずトークンを使う。足りない場合はここに追加してから使う。

### 色

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#0b1019` | ページの背景。地図の海と同じ色 |
| `--surface` | `#121927` | パネル、シート、モーダルの地 |
| `--surface-2` | `#1a2233` | 面の上に置く要素（選択中のタブ、副ボタン、候補リスト） |
| `--line` | `#243047` | 区切り線、枠線 |
| `--text` | `#e7eaf0` | 本文 |
| `--muted` | `#8d96aa` | 補足、ラベル、無効な項目 |
| `--accent` | `#f2a93b` | 訪問国、主要ボタン、強調する数字、フォーカスの枠 |
| `--accent-strong` | `#ffd27a` | アクセントの中でさらに目立たせたいもの（プレビューで、その年に初めて訪れた国） |
| `--on-accent` | `#1d1305` | アクセント色の上に置く文字やアイコン |
| `--danger` | `#ff7a6b` | エラー、非対応の案内（背景に使うときは透明度を下げる） |

### 角丸

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--radius-s` | `8px` | 一覧の行、タグ |
| `--radius-m` | `12px` | 入力欄、ボタン |
| `--radius-l` | `20px` | シート、モーダル |

### 書体

- 端末のサンセリフ体（`--font-sans`）を使う。外部通信なしで表示する方針（`openspec/specs/world-map`）のため、Web フォントは使わない。
- 基本の文字サイズは 14px。上部バーのアプリ名は 15px・太字。
- 年や国数など、変化する数字には等幅数字（`font-variant-numeric: tabular-nums`）を使い、アニメーション中に数字の幅が揺れないようにする。

## 地図の配色

Canvas に描くため、CSS 変数ではなく `apps/web/src/map/drawWorldMap.ts` の `MAP_COLORS` に値を持つ。トークンを変えたときは両方をそろえる。

| 要素 | 値 | 方針 |
| --- | --- | --- |
| 海 | `#0b1019` | `--bg` と同じ。地図の外側の余白もこの色で塗る |
| 経緯線 | `rgba(255, 255, 255, 0.045)` | かろうじて見える程度にし、地図の手がかりとして使う |
| 未訪問の国 | `#232c3f` | 彩度を抑え、訪問国を引き立てる |
| 国境 | `#0b1019`（0.5px） | 海と同じ色で国と国の間に細い隙間を作る |
| 訪問済みの国・マーカー | `#f2a93b` | `--accent` と同じ |
| マーカーの輪 | `rgba(242, 169, 59, 0.55)` | 小さな訪問国の位置を示す輪。中心の点より淡くする |
| その年に初めて訪れた国 | `#ffd27a` ＋ 光彩 | `--accent-strong`。プレビューのコマで、ハイライト色から 0.6 秒かけて変わり、光彩が強まる |

- 地図は縦横比を保って描画領域に収まる最大の大きさにし、中央に置く。
- マーカーの大きさは地図の幅に比例させ、動画の高解像度でも同じ見え方にする。

## レイアウト

### 共通

- 画面は「上部バー（高さ 52px）＋残りすべての領域」の2段にし、高さは `100dvh` に合わせる。
- 上部バーには、左にロゴとアプリ名、右に共有などのアイコンボタンを置く。
- 画面の端との余白は 16px。

### PC

- **記録の画面:** 左に幅 360px のパネル（入力欄と記録の一覧）、右に地図を置く。
- **プレビューの画面:** 中央に 9:16 のプレビュー、右に幅 320px のパネル（コマの一覧と書き出しボタン）を置く。コマの一覧は年とまとめを並べ、表示中のコマを強調し、押すとそのコマの先頭へ移動する。パネルの下端に書き出しの欄（書き出しボタン、進捗、完了時の情報）を置く。
- 記録とプレビューは、上部バー右の切り替えボタンで行き来する。

### スマートフォン

- 記録とプレビューは、画面下のタブ（高さ 64px）で切り替える。記録の画面の「＋ 記録を追加」ボタンはタブの上に置く。
- プレビューの画面は、上にプレビュー、下に操作を置く。操作の並びの最後に「書き出す」ボタンを置き、押すと書き出しのシートを開く。
- 入力、書き出し、共有などの操作は、下から出るシート（上の角を `--radius-l` で丸める）に置く。シートの背後は半透明の黒で覆う。

## 将来の画面の指針

issue #11 で承認されたモックの要点。各 issue の実装時に詳細を詰める。

### 記録（#6）

- 入力欄は「年の選択＋国の検索（日本語名）＋追加ボタン」を横に並べる。スマートフォンではシートの中で縦に並べる。
- 国の候補リストでは、入力した文字に一致する部分を `--accent-strong` で示す。
- 一覧は年ごとにまとめ、新しい年を上にする。各行には国コード（等幅の小さなバッジ）、国名、削除ボタンを並べる。同じ国を以前の年にも訪れている場合は「再訪」のタグを付ける。
- スマートフォンでは、上に地図（高さの約 4 割）、その下に一覧、最下部に「＋ 記録を追加」ボタンを置く。ボタンで入力欄のシートを開く。一覧を常に見せ、その場で削除できるようにするためである（#6 のモックで承認）。
- シートは追加後も開いたままにし、国の欄だけを空にして年は残す。同じ年の国を続けて登録しやすくするためである。
- 同じ年に登録済みの国は、候補に「追加済み」と表示して選べないようにする。
- 訪問国の数（同じ国の複数年の記録は 1 か国と数える）は、地図の左下に重ねて `--accent` の大きな数字で示す。
- ブラウザ内に保存できない環境では、一覧の上に `--danger` の案内を出す。

### プレビュー（#3）

- 9:16 の画面で、年ごとに1コマずつ表示する。コマは文字も含めてすべて Canvas に描き、動画の書き出しと同じ描画関数（`apps/web/src/timeline/drawFrame.ts`）を使う。
- 配置と文字の大きさは、コマの基準の大きさ 1080×1920 に対する px で決め、表示する幅に合わせて拡大・縮小する。コマの配色は `drawFrame.ts` の `COLORS` に値を持ち、デザイントークンと一致させる。
- 1 年のコマは 2 秒、まとめのコマは 4 秒表示する。コマの切り替えは即時で、コマの中では次の動きだけを付ける。
  - 最初の 0.3 秒で上部の文字がフェードインする。
  - 最初の 0.6 秒で、その年に初めて訪れた国が強調色と光彩に変わり、累計の国数が前の年の値から数え上がる。
  - まとめのコマでは、最初の 0.5 秒で国の一覧がフェードインする。
- コマの構成:
  - 上部: 小さく字間を広げたアプリ名、大きな年（太字）、「初めて訪れた国 +N」と国名（最大 2 行。収まらない分は「ほか N か国」）。再訪だけの年は「再訪：」に続けて国名を `--muted` で示す
  - 中央: 地図。累計の訪問国を `--accent`、その年に初めて訪れた国を `--accent-strong` と光彩で示す
  - 下部: 累計の国数（大きな数字、`--accent`）と、全コマ中の位置を示す進捗バー
- 最後のコマは、期間（最初の年〜最後の年）、累計の国数、訪れた国の一覧（最大 4 行。収まらない分は「ほか N か国」）をまとめて表示する。
- 操作は「最初から再生」「再生／停止」「再生位置のバー」の順に並べる。

### 書き出し・共有（#5、#8）

- 書き出し中は進捗バー、現在のフレーム数と割合（例：「150 / 300（50%）」）、キャンセルボタンを表示する。書き出しを始めたらプレビューの再生は止める。
- スマートフォンで書き出し中にシートを閉じたら、書き出しをキャンセルする。見えないところで重い処理を続けないためである。
- 完了時はファイル名・長さ・解像度・形式（H.264 / VP9）と「共有・保存」ボタン、「閉じる」ボタンを表示する。共有シートは利用者の操作の中でしか開けないため、完了時に自動では開かない。
- 書き出しに対応していない環境では、書き出しボタンを無効にし、`--danger` の案内で対応している環境を示す（「この環境では動画を書き出せません。PC・Android の Chrome、iPhone の Safari で書き出せます。」）。
- 書き出しに失敗したら、`--danger` の案内に理由を示し、「もう一度書き出す」ボタンを置く。
- 共有の選択肢（リンクで共有、ファイルに書き出す、ファイルから読み込む）は、アイコン、名前、短い説明を1行にまとめて並べる。記録がサーバーに送信されないことを添える。
